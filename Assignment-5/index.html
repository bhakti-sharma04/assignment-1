HTML Basic Tutorial

Welcome to HTML Tutorial

HTML stands for HyperText Markup Language. It is used to create simple web pages.

1. HTML Basic Structure

Every HTML document has standard tags:

<html>
  <head>
    <title>My Page</title>
  </head>
  <body>
    <h1>Hello World</h1>
  </body>
</html>
2. Common HTML Tags
  • <h1> to <h6>: For headings
  • <p>: For writing paragraphs
  • <a>: For creating links
  • <img>: For displaying pictures
  • <ul> and <li>: For bullet lists
3. Simple Table Example
Tag Meaning
<table> Defines a table
<tr> Table row
<td> Table data (cell)
